## Estrutura

Cada parte contém as pastas dos seus capítulos. Cada capítulo tem uma pasta `exemplos/` para acompanhar os trechos praticados durante a leitura e uma pasta `exercicios/` para organizar as resoluções das atividades propostas.

A Parte 02 também contém `projetos/invasao-alienigena/`, `projetos/visualizacao-de-dados/` e `projetos/aplicacao-web/`. Esses espaços permitem continuar os projetos entre capítulos.

## Como acompanhar o estudo

1. Ao começar um capítulo, preencha o início e altere o status para **Em andamento** no [PROGRESSO.md](PROGRESSO.md).
2. Leia e pratique. Registre as anotações no README do capítulo, os programas de exemplo em `exemplos/` e as resoluções em `exercicios/`.
3. Marque cada exercício com `[x]` após cumprir seu enunciado completo no livro. As atividades permanecem com a numeração original; os enunciados e as soluções não foram reproduzidos.
4. Ao cumprir os critérios de conclusão do capítulo, altere seu status para **Concluído** e preencha a data no progresso geral.
5. Atualize os totais do progresso geral. Esses números são manuais; as checklists dos capítulos são a referência para os exercícios realizados.
6. Registre também a leitura do material inicial e dos apêndices para completar o livro.

O progresso marcado reflete as atividades registradas até agora. Os programas nas pastas dos capítulos são arquivos de estudo do projeto; consulte cada README para ver quais exemplos e exercícios eles acompanham.
